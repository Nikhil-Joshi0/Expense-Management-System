# Expense Management System

A console-based **Expense Management System developed in C** as a 2nd-semester academic project. The application allows users to register, log in securely, and manage their personal expenses through a simple menu-driven interface.

## Features

- User Registration
- User Login and Authentication
- Username and Password Validation
- Expense Management
- Add Expense Records
- View Expense Records
- Search Expense Records
- Update Expense Records
- Delete Expense Records
- Calculate Total Expenses
- Category-based Expense Management
- File Handling for Data Storage
- Menu-driven Console Interface

## Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **IDE:** Visual Studio Code
- **Concepts Used:**
  - Structures
  - Functions
  - Arrays
  - Strings
  - Pointers
  - File Handling
  - Conditional Statements
  - Loops
  - Modular Programming
